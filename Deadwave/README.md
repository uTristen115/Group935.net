# Deadwave

Deadwave is a browser-based, top-down zombie survival mini game built from the provided design document. It uses plain HTML, CSS, and JavaScript with the Canvas API, so it can run directly from the workspace without installing dependencies.

## Play

Open `index.html` in a browser.

## Controls

- `W`, `A`, `S`, `D`: move
- Mouse: aim
- Left click: shoot
- `R`: reload
- `E`: interact / repair
- `F`: melee
- `Shift`: sprint
- `Space`: dash
- `1`, `2`: swap weapon slots
- `Esc`: pause

## Included Systems

- Round-based zombie spawning and scaling
- Points for hits, kills, headshots, melee kills, repairs, and round survival
- Two weapon slots, wall buys, ammo, reloads, and weapon upgrades
- Repairable window barriers
- Unlockable rooms, power switch, perk machines, weapon crate, and upgrade station
- Synthesized original sound effects through the Web Audio API
- Local high-score tracking
